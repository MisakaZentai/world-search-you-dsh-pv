# 本地输入

本目录除本说明以外的内容均被 Git 忽略，不能随代码 ZIP 发布。

## 音源

自备合法取得的 Mili《world.search(you);》Hue 版，转换为 44.1 kHz、双声道、16 bit PCM WAV，命名 `song.wav`。参考时长 292.50 秒；精确文件指纹见 `../data/input_fingerprint.json`。代码不会下载歌曲。

`check` 严格核对 WAV SHA-256。其他来源或不同转码结果可能不匹配，不能据此判断音源是否合法，也不能无检查地沿用时间线。需要先核对波形、起点和逐词时序，再有意识地更新指纹和时间数据。

## 英文歌词

将可使用的逐句歌词存为 UTF-8 `lyrics.lrc`；或显式执行 `python build.py lyrics --fetch`，通过 LRCLIB 条目 19234404 下载到本机。下载不会改变歌词的权利归属。

构建器用公开包中每行、每词的 SHA-256 和词数验证输入，任何不匹配都会停止，不写出时间文件。公开包只有时间与指纹，没有歌词全文。

## 可选中文及编号

`zh_subtitles.json` 包含两个以行号字符串为键的对象：`base`（基础译文）和 `display`（字幕使用的译文）。需要覆盖原片的 67 个行号。字符段长度和英文词下标在 `../data/zh_alignment.json`，去掉 `，、` 后长度必须与各段之和匹配。其他译文需要同步调整该数字排版表；本仓库不提供原片译文。

`subtitle_ids.json` 可提供 `en`、`zh` 两个对象。每个行号对应一个数组，每个词/中文块对应一组 token ID。它们应与自备歌词及所用 tokenizer 相符。未提供时编号为空；不要把伪造编号当作真实 tokenizer 结果。

先放入上述可选输入，再运行 `build.py lyrics`。不提供中文与编号也可构建，英文字幕保留，中文和编号留空。精确复现原片需要这些本地输入以及相同的字体/浏览器环境。
